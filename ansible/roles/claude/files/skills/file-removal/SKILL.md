# 概要

ふだんの退避（`evacuate -n <作業名> <パス>...`）の規則はグローバル指示の「ファイルを取り除くとき」にある。
この skill は、そこから外れる場面の手順を持つ。

## 権限が足りないとき

`evacuate` が `sudo mv -n …` の 1 行を出したら、その 1 行だけをユーザーに実行してもらう。
実行後に `evacuate` が示す `ls -ld` で、移動元が消えて移動先にあることを確かめる。

## 戻すとき

退避したときに表示される `evacuate --restore <退避先のパス>` を使う。`mv` で手で戻さない。

## 退避したものを消すとき

期限（グローバル指示の「ファイルを取り除くとき」の日数）を過ぎたものは SessionStart フック（`prune-evacuated.py`）が消す。それより新しいものを
消すのは、ディレクトリ名を挙げた承認があるときだけで、消し方は下の完全削除と同じである。

## 完全削除が要るとき

容量の逼迫や機密の抹消で完全削除が要るときは、`AskUserQuestion` で承認を得てから
`rm -rf -- '<パス>'` を示し、ユーザーに実行してもらう。容量を空けたいときは、新たに消すものより
先に `~/.local/state/evacuated/` の古いものを候補に挙げる。
