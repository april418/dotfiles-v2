# 見た目の型

見つけ方の一覧である。使い方は SKILL.md の「考え方」に従う。`text.*` と `looks.*` は `page_audit.js` の結果、それ以外の名前は `count_patterns.py` の出力である。

Show HN の採点では 4 つ以上を High に分けている（[Adrian Krebs](https://www.adriankrebs.ch/blog/design-slop/)、22%）。この区切りは分類の便宜である。

## 第一世代

| 型                                          | 見つけ方                                                                           |
| ------------------------------------------- | ---------------------------------------------------------------------------------- |
| 紫〜青のグラデーション                      | `gradient()` の件数を見て、色は実画面かソースで読む。Tailwind は「紫〜青の色止め」 |
| 白地に紫                                    | アクセントの色相と背景を見る                                                       |
| Inter 一択                                  | `text.families` の偏り                                                             |
| 中央揃えのヒーローとアイコン付きカード 3 枚 | 実画面を見る                                                                       |
| 絵文字のアイコン                            | `count_patterns.py` の「絵文字と文字記号」                                         |

## 第二世代

| 型                                | 見つけ方                                                                      |
| --------------------------------- | ----------------------------------------------------------------------------- |
| 見出しの 1 語だけのグラデーション | `looks.gradientText`、`background-clip: text`                                 |
| オーロラ状のぼかし背景            | `radial-gradient` の重なりと `filter: blur` を実画面で見る                    |
| 全節の大文字の eyebrow            | `text.uppercase`、`text-transform: uppercase`、節ごとの見出しの上を見る       |
| `01 — Titles` のような番号ラベル  | 番号が順序を表していないものを探す                                            |
| ツールバーのガラス                | `looks.glass`、`backdrop-filter`                                              |
| 全部 pill                         | `border-radius` の上位に `999px` や `50%` が偏っている、`rounded-full`        |
| hover で浮く                      | `hover で浮く`、`hover:-translate-y`                                          |
| スクロール出現                    | `@keyframes` と IntersectionObserver。JS が動くまで `opacity: 0` のものは欠陥 |
| 統計の帯                          | 見出しの下に大きな数字が並ぶ。件数が 0 の統計も見る                           |
| カードの入れ子                    | 枠と影のある箱の中に、また枠と影のある箱がある                                |
| 片側だけ太い枠                    | `片側だけの太い枠`                                                            |
| 色付きのステータスドット          | 状態を持たない項目に点が付いている                                            |
| 文字記号のアイコンと SVG の混在   | `count_patterns.py` の「絵文字と文字記号」と SVG の部品を並べて見る           |

## 回避策の定番

既定値を避けた結果として選ばれやすい。SKILL.md の「考え方」にあるとおり、これも型として数える。

| 型                             | 見つけ方                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Space Grotesk                  | `text.families`                                                                                        |
| クリーム色の背景               | `body` の背景色を実画面で見る                                                                          |
| 大きなイタリックのセリフ見出し | 見出しの `font-style` と書体を実画面で見る                                                             |
| 見出しの 1 語だけのイタリック  | 見出しの中の `em`、`i` と子要素の `font-style` を実画面で見る                                          |
| 小さなラベルだけ等幅           | `text.families` に等幅の書体が出たら、その書体の要素を実画面で見て、小さなラベルに偏っていないかを見る |

作るときは frontend-design の較正の一覧も当てる。`→` の付いたリンク、`A · B · C` の連結、`WORD — fragment` のラベルなどはそちらにある。

## 間引き方

- 型を全部消さない。製品の内容に結び付くものを 1 つ残し、ほかを静かにする
- 飾りの箱は、中の実データを見せるものに置き換えられないかを先に考える
- アイコンは 1 系統にそろえる
- 動きは操作の応答に絞り、`prefers-reduced-motion` で止まることを確かめる

検出の閾値の例は [pixelslop のパターン一覧](https://cdn.jsdelivr.net/npm/pixelslop@0.3.8/dist/skill/resources/ai-slop-patterns.md) にある。ツールの作者の経験則なので、基準ではなく見つけ方の参考にする。
