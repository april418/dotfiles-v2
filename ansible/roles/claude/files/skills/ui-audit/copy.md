# 文言の点検

画面の文字を全部書き出し、見出しと説明文を表にして、1 文ずつ残す文、書き換える文、消す文に分ける。

| 点検項目                             | 判断                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------ |
| 製品名を隠しても他社に使い回せる文   | 書き換える。その製品にしか言えない事実（扱う対象、件数、できる操作）を入れる               |
| 比喩や雅語                           | 機能の説明に置き換える。抽斗、一座の舞台、潜り込む、回遊、世界観、エディトリアルのような語 |
| 実際に無い機能の説明                 | 操作して確かめ、無ければ消す。将来の予定を現在形で書かない                                 |
| 定型語                               | streamline、empower、Learn More、Get Started の連発を、その操作で起きることの言葉に換える  |
| 操作の直前にある、操作を説明しない文 | 消す。面積を機能に返す（[area-measurement.md](area-measurement.md)）                       |

書き換えの形は次のとおりである。

| 書き換える前       | 書き換えた後               |
| ------------------ | -------------------------- |
| 物語の抽斗をひらく | 作品名と作家名で検索できる |
| 世界観に潜り込む   | 作品ごとの一覧を見る       |
| Get Started        | 無料で登録する             |

残す文は、製品の内容から来ていて、ほかのサイトでは言えないものである。トップページの文面の扱いは [area-measurement.md](area-measurement.md) の「判断」に従う。

`count_patterns.py` の「定型の英語」は英語の語だけを数える。和文の比喩は機械で拾えないので読んで判断する。
